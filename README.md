# 三体人物思维专区

> 深入本质，一通百通。 · Zero Wong

把《三体》人物的判断、行动与失败整理成可调用的 AI Skills。每个人物有独立仓库，本专区负责导航与比较。

## 怎样选择

- 长期规划与关键项目：章北海、维德。
- 现场问题与人的行为：史强。
- 文明判断与信息交互：叶文洁、智子。
- 面壁计划比较：泰勒、雷迪亚兹、希恩斯。

## 怎样使用

进入人物仓库，下载完整文件，将目录以仓库名放入 Codex 的 skills 目录。重新开始会话，提出“用某某视角分析……”即可。每个仓库包含入口 SKILL.md、调研笔记和调用说明。

建议给出具体目标、事实、限制与备选方案，并要求区分小说依据和现实推断。可以用两个人物分别分析同一问题，再比较结论。

## 阅读边界

仅收录目前已完成的 8 个 Skills，不代表《三体》全部人物。含小说剧透，以小说为基础，保留各人物的失败与局限；不把现实推断包装为人物原话。泰勒仓库注明中文版本差异。
